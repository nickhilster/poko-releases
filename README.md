# Poko — Releases

This repo hosts **public download builds** for [Poko](https://poko.teambotics.app/), a desktop pet that reacts to your coding agent sessions in real-time.

Poko's source code lives in a private repository. This repo exists solely so release installers can be downloaded publicly (private-repo release assets aren't downloadable without authentication).

## Download

Get the latest build from [Releases](https://github.com/Teambotics-BackBurner/poko-releases/releases/latest), or visit [poko.teambotics.app](https://poko.teambotics.app/).

Currently available:
- **Windows (x64)**

Windows ARM64, macOS, and Linux builds are coming in a future release.
